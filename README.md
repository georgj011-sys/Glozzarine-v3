# Glizzarine 3

## Update
In your existing GitHub repository: Add file > Upload files > drag in ALL files from this folder
EXCEPT build.yml (it is already in the right place). Commit, and the build starts.

## What's new in version 3
- The 8 Play knobs control real settings directly and always show the preset's actual values.
  Glide at 0 means no glide. Reverb at 0 means no reverb. Your KeyLab knobs control these 8.
- Pages: Play, Sound, Motion, Effects, Arp, Setup. Nothing is hidden anymore.
- Every effect has its full set of controls and an on/off switch. Turning up a knob of a switched-off
  effect switches it on automatically.
- Detune is back on each oscillator.
- Keys fade out naturally while held and ring out when released. Every note has a minimum fade,
  so notes no longer click when they stop.
- Clean output limiter: many notes at once no longer distort.
- 102 presets: 20 Pads, 22 Keys, 12 Leads, 10 Bass, 6 Plucks, 10 Arps, 14 Video, 8 Weird.
  Clearer sounds with at most three effects each. Glide only where it is the point of the sound.
- Arp display shows exactly one cell per step of the bar, with the current step highlighted.
